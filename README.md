<h1 align="center">راه‌یاب افغانستان — Rahyab Afghanistan</h1>
<p align="center"><b>مسیر درست، سفر آسان</b></p>

اپلیکیشن اندروید متن‌باز نقشه و مسیریابی افغانستان — مثل نشان و بلد، اما **رایگان، بدون سرور اختصاصی، با حالت کاملاً آفلاین** و زبان پیش‌فرض **دری افغانستان** (به‌علاوه پشتو، فارسی و انگلیسی).

> **نسخه ۰٫۹٫۱:** پنج صدای دری داخل برنامه (امیر، دلارا، فرید، نگار، همایون — هرکدام ۲۹ عبارت، آفلاین) و انتخاب صدا با دکمه پخش آزمایشی به سبک نشان؛ تیرک جهت همیشه روی مسیر از مبدا تا مقصد؛ هشدارهای سرعت‌گیر/تصادم/زحمت/کمره؛ رانندگی آزاد؛ صفحه کامل رادیو؛ تنظیمات مسیریابی و برچسب‌های فقط-افغانستان روی نقشه.

## شروع سریع (بدون کمپیوتر — فقط با GitHub)

1. یک مخزن جدید در GitHub بسازید و همه فایل‌های این پروژه را آپلود کنید.
2. در `gradle.properties` مقدار `rahyabGithubUser` را با نام کاربری GitHub خود عوض کنید (یک خط).
3. به تب **Actions** بروید و `Build APK` را اجرا کنید — APK در بخش **Artifacts** آماده است.
4. برای بسته‌های آفلاین، Workflow **Build Map Packages (All Provinces)** را اجرا کنید — هر ۳۴ ولایت در ۵ شارد موازی ساخته و در Releases (تگ `map-data`) با `manifest.json` منتشر می‌شود.
5. در برنامه، تب **بسته‌های آفلاین** را باز کنید و ولایت خود را دانلود کنید — از این بعد نقشه، جست‌وجو و مسیریابی بدون انترنت کار می‌کند.

## نصب روی گوشی

فایل APK را دانلود کنید. اگر اندروید هشدار «منبع ناشناس» یا Play Protect داد، نصب از این فایل را اجازه دهید. برای گوشی‌های جدید `arm64-v8a` و برای گوشی‌های قدیمی `armeabi-v7a` را بگیرید؛ اگر مطمئن نیستید فایل `universal` را بگیرید.

## بسته‌های آفلاین — تمام ۳۴ ولایت

هر بسته = کاشی PMTiles + گراف مسیریابی + اندیس جست‌وجو + سبک. هر ولایت جداگانه دانلود و نصب می‌شود و می‌توان چند ولایت را هم‌زمان نصب داشت.

| گروه | ولایت‌ها | حجم تقریبی |
|---|---|---|
| مرکز | کابل، پروان، لوگر، میدان وردک، کاپیسا، پنجشیر | ≈ ۱۵۰MB |
| بزرگ شهرها | هرات، قندهار، بلخ، ننگرهار | ≈ ۱۲۰MB |
| شمال | بلخ، کندوز، تخار، بغلان، سمنگان، سرپل، جوزجان، فاریاب، بادغیس | ≈ ۲۵۰MB |
| جنوب و غرب | هلمند، غزنی، زابل، ارزگان، فراه، نیمروز، غور، بامیان، دایکندی | ≈ ۲۰۰MB |
| شرق | کنر، نورستان، لغمان، خوست، پکتیا، پکتیکا، بدخشان | ≈ ۱۵۰MB |

- جزئیات: [docs/MAP_PACKAGES.md](docs/MAP_PACKAGES.md) و قالب فایل‌ها: [docs/DATA_FORMATS.md](docs/DATA_FORMATS.md)
- ساخت و انتشار با Workflow جداگانه (۵ شارد موازی) و اعتبارسنجی خودکار انجام می‌شود؛ فایل خراب هرگز منتشر نمی‌شود.
- **محدودیت شناخته‌شده:** مسیر بین‌دو-ولایتی در مرز محدوده‌ها ممکن است قطع شود؛ برای سفر بین‌ولایتی هر دو ولایت را نصب کنید.

## ساخت از سورس (کمپیوتر)

```bash
git clone https://github.com/USER/rahyab-afghanistan
cd rahyab-afghanistan
./gradlew assembleDebug        # APK آزمایشی
./gradlew testDebugUnitTest    # آزمون موتور آفلاین (نیازمند داده بسته؛ اختیاری)
```
