# سرور راه‌یاب — Cloudflare Worker + D1

این بخش، ضمیمهٔ ۱ چک‌لیست (سیستم جامع اطلاعات جاده‌ای) را به‌صورت سرور اجرا می‌کند:
ثبت، تأیید، جست‌وجو، نمایش، ویرایش و همگام‌سازی همهٔ مکان‌ها و تجهیزات جاده‌ای افغانستان.

## راه‌اندازی (یک بار)

```bash
cd worker
npm install
npx wrangler login
# ساخت دیتابیس D1 (اگر ساخته نشده):
npx wrangler d1 create rahyab-reports
# شناسهٔ خروجی را در wrangler.toml جای database_id بگذارید
# ساخت جداول:
npx wrangler d1 execute rahyab-reports --file=schema.sql --remote
# انتشار:
npm run deploy
```

پس از انتشار، نشانی Worker (مثل `https://rahyab-worker.<account>.workers.dev`)
را در `Config.kt` روی `POI_API_BASE` بگذارید یا داخل برنامه در
«تنظیمات پیشرفته → سرور اطلاعات جاده‌ای» ثبت کنید.

## جداول D1 (بخش ششم ضمیمهٔ ۱)

| جدول | کاربرد |
| --- | --- |
| `road_pois` | همهٔ مکان‌ها و امکانات ثابت جاده‌ای (کمره، دست‌انداز، پولیس، عوارض، پمپ بنزین، شفاخانه…) |
| `road_poi_reports` | گزارش کاربران دربارهٔ مکان‌های ثابت (خرابی، حذف، جابه‌جایی، تعطیلی…) |
| `road_poi_votes` | رأی تأیید/رد کاربران — هر دستگاه یک رأی |
| `road_services` | خدمات عمومی و رفاهی با تیلفون و ساعات کاری |
| `road_equipment` | تجهیزات کنترولی با جهت، سرعت مجاز تأییدشده و منبع |
| `live_reports` | گزارش‌های زندهٔ ۲۴ ساعتهٔ جاده (بخش پنجم) |

## APIها (بخش دهم ضمیمهٔ ۱)

| متد و مسیر | کار |
| --- | --- |
| `GET /api/v1/health` | وضعیت سرویس |
| `GET /api/v1/pois` | فهرست مکان‌ها — فیلتر `bbox` یا `minLat…`، `category`، `province`، `status`، `since`، `limit` |
| `GET /api/v1/pois/:id` | جزئیات مکان + شمار رأی‌ها و گزارش‌های باز |
| `POST /api/v1/pois` | ثبت مکان جدید — تکراری (همان دسته در ۳۵ متری) خودکار تشخیص داده می‌شود |
| `POST /api/v1/pois/:id/verify` | رأی تأیید/رد؛ ۲ تأیید → `user_verified`، ۳ رد → غیرفعال |
| `POST /api/v1/pois/:id/report` | گزارش خرابی/حذف/اطلاعات غلط؛ ۳ گزارش مستقل «حذف» → غیرفعال |
| `GET /api/v1/equipment` | تجهیزات کنترولی با فیلتر نوع و محدوده |
| `GET /api/v1/services` | خدمات عمومی با فیلتر نوع و محدوده |
| `GET /api/v1/pois/nearby` | مکان‌های نزدیک نقطه (`lat`, `lon`, `radius`) |
| `GET /api/v1/pois/along-route` | مکان‌های کنار مسیر (`route=lat,lon;…`, `corridor`) |
| `GET /api/v1/pois/search` | جست‌وجوی متنی (`q`، حداقل ۲ نویسه) |
| `GET /api/v1/reports` | گزارش‌های زندهٔ معتبر (۲۴–۴۸ ساعت) |
| `POST /api/v1/reports` | ثبت گزارش زنده |

## قواعد صحت‌سنجی و حریم خصوصی (بخش یازدهم ضمیمهٔ ۱)

- هر مکان با `verification_status = unverified` ثبت می‌شود؛ فقط دو رأی مستقل
  آن را `user_verified` می‌کند و منبع رسمی (`source=official`) مستقیماً
  `official` می‌ماند.
- `speed_limit` فقط در `properties_json` و به‌صورت تأییدنشده ذخیره می‌شود؛
  نمایش قطعی آن نیازمند منبع رسمی است.
- متن‌های دارای واژه‌های امنیتی حساس (ایست بازرسی، پایگاه، نیروهای امنیتی و…)
  رد می‌شوند — هیچ موقعیت گشت متحرک یا ایست موقت منتشر نمی‌شود.
- هر دستگاه (`device_id`) برای هر مکان فقط یک رأی دارد.
- مکان‌های حذف‌شده غیرفعال می‌شوند (`is_active=0`) ولی سابقهٔ آن‌ها می‌ماند.
- محدودکنندهٔ نرخ ساده روی همهٔ نوشتن‌ها (۴۰ درخواست در دقیقه برای هر IP).

## کنترل مصرف (بخش دوازدهم ضمیمهٔ ۱)

- همهٔ خواندن‌ها با `LIMIT` سقف‌دار (متغیرهای `wrangler.toml`).
- برنامه فقط مکان‌های محدودهٔ نقشه یا کنار مسیر را می‌گیرد — هرگز همهٔ کشور.
- همگام‌سازی دلخواه با `since=<updated_at>` که فقط تغییرها را برمی‌گرداند.
