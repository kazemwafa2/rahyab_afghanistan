# معماری نقشه و ریلیز `map-data` (MAPAF)

## منبع‌های داده
| دارایی در ریلیز `map-data` | نقش | مصرف‌کننده |
|---|---|---|
| `af.pmtiles` (≈۱۵۲ MiB، PMTiles v3، زوم ۰–۱۴، OpenMapTiles) | **نقشهٔ آنلاین**: داده‌های اختصاصی افغانستان (سرک، ساختمان، آب، نام‌ها، مکان‌ها، قله‌ها) | برنامه با HTTP Range از `Config.ONLINE_PMTILES_URL` می‌خواند |
| `manifest.json` + `afghanistan_full-…rahpkg.zip` | **بستهٔ آفلاین**: کاشی + گراف مسیریابی (RAFG1) + ایندکس جست‌وجو (RAFI1) | صفحهٔ «بسته‌های آفلاین» |
| `map.af-data.zip` | آینهٔ ابزارهای توسعه (viewer، سبک، آیکن، `osm-poi`، `places`)؛ **برنامه از آن نمی‌خواند** | توسعه‌دهنده |
| `SHA256SUMS.txt`، `APK-SHA256SUMS.txt` | جمع‌های کنترلی | — |

## ترتیب انتخاب منبع کاشی (MainActivity)
1. اینترنت روشن + `af.pmtiles` در دسترس (آزمون Range → HTTP 206، هدر PMTiles v3) → `pmtiles://…/af.pmtiles` (آنلاین، هر بار تازه‌ترین).
2. بستهٔ کامل کشوری نصب‌شده → همان فایل محلی (آفلاین؛ با قطع/برگشت اینترنت خودکار جابه‌جا می‌شود).
3. هیچ‌کدام → OpenFreeMap (OpenStreetMap جهانی) تا نقشه خالی نماند.

مکان‌های همهٔ زوم‌ها از `assets/poi/poi_all.geojson` (places + osm-poi + کاشی‌ها) می‌آیند؛ سبک نقشه از `assets/style/*.json`.
