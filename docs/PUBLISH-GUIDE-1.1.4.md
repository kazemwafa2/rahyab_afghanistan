# راهنمای انتشار نقشهٔ اختصاصی کامل — ریلیز map-data

این راهنما برای شماست: چطور بستهٔ «نقشهٔ اختصاصی کامل افغانستان» را منتشر کنید تا
همهٔ کاربران راه‌یاب آن را در برنامه ببینند و دانلود کنند.

## این بسته چیست؟

| فایل | حجم | توضیح |
|---|---|---|
| `afghanistan_full-2026-11-17.rahpkg.zip` | ~۱۵۹MB | نقشهٔ برداری کامل افغانستان (۳۴ ولایت، زوم ۰-۱۴) + گراف مسیریابی کشوری + اندیس جست‌وجو |
| `manifest.json` | ~۲۰KB | فهرست بسته‌ها (۳۶ بسته: پایه + نقشهٔ اختصاصی کامل + ۳۴ ولایت) |

دادهٔ کاشی از فایل عمومی map.af (`tiles.map.af/basemap/af.pmtiles`) گرفته شده —
دادهٔ رسمی OpenStreetMap، بدون هیچ API، با انتساب کامل در NOTICE.md و شناسنامهٔ بسته.

## روش ۱ — بارگذاری دستی (سریع‌ترین راه)

۱. وارد https://github.com/kazemwafa2/rahyab_afghanistan/releases/tag/map-data شوید.
۲. روی «Edit release» (مدیریت/ویرایش) بزنید.
۳. این دو فایل را در بخش Assets بکشید و رها کنید:
   - `afghanistan_full-2026-11-17.rahpkg.zip`
   - `manifest.json` (نسخهٔ جدید — فایل قدیم را جایگزین می‌کند؛ گزینهٔ Replace را تأیید کنید)
۴. «Update release» را بزنید. تمام!

از این لحظه، برنامهٔ راه‌یاب (نسخهٔ ۱٫۱٫۱ به بالا) با زدن «بروزرسانی» در
«بسته‌های نقشهٔ آفلاین»، بستهٔ «افغانستان — نقشهٔ اختصاصی کامل» را می‌بیند؛
حتی اگر manifest نتوانست خوانده شود، اسکن پشتیبان دارایی‌های ریلیز آن را پیدا می‌کند.

## روش ۲ — خودکار با ورک‌فلو (برای انتشارهای بعدی)

GitHub → تب **Actions** → **publish-map-data** → **Run workflow**.
ورک‌فلو همهٔ بسته‌ها را از نو می‌سازد، نقشهٔ اختصاصی کامل را خودش از map.af
می‌گیرد، manifest را بازتولید و همه را در ریلیز map-data بارگذاری می‌کند
(مرحلهٔ تازه: `build nationwide full package`).

## پس از انتشار، در برنامه چه اتفاقی می‌افتد؟

۱. کاربر وارد «بسته‌های نقشهٔ آفلاین» می‌شود و بستهٔ
   **«افغانستان — نقشهٔ اختصاصی کامل (همهٔ ۳۴ ولایت)»** را با حجم ~۱۵۹MB می‌بیند
   (توصیه: وای‌فای؛ دانلود با ادامهٔ پس از قطع اتصال پشتیبانی می‌شود).
۲. پس از نصب، نقشهٔ کامل (کوچه تا عمارت) در **هر دو حالت آنلاین و آفلاین** از
   همین فایل محلی رندر می‌شود — آنلاین و آفلاین دقیقاً یک نقشه می‌شوند.
۳. مسیریابی بین‌ولایتی و جست‌وجوی سراسری از گراف و اندیس همان بسته استفاده می‌کند.
۴. بسته‌های ولایتی قبلی دست‌نخورده می‌مانند و برای مسیریابی خیابانی کامل داخل
   ولایت همچنان به‌کار می‌روند.

## انتشار خود APK نسخهٔ 1.1.4

APKهای امضاشده با همان کلید قبلی (alias `rahyab`) آماده‌اند:

- `rahyab-1.1.4-universal.apk` — برای همهٔ گوشی‌ها
- `rahyab-1.1.4-arm64-v8a.apk` و `rahyab-1.1.4-armeabi-v7a.apk` — تفکیک معماری

GitHub → Releases → Draft a new release → تگ `v1.1.4` → توضیحات از
`docs/RELEASE-NOTES-1.1.4.md` → بارگذاری APKها → Publish.
پس از انتشار، «به‌روزرسانی خودکار» داخل برنامه هم نسخهٔ تازه را پیدا می‌کند
(ریلیز latest APK دارد و versionCode 28 از نام تگ خوانده می‌شود).

## رمز امضا

رمز keystore همان رمز قبلی پروژه است (متغیرهای محیطی `KEYSTORE_PASSWORD` /
`KEY_ALIAS` / `KEY_PASSWORD` در ورک‌فلو build-apk). رمز فقط از GitHub Secrets
خوانده می‌شود و در هیچ فایلی نوشته نشده است.
