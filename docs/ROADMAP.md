# نقشه راه

1. **۰.۱ ✔:** نقشه، GPS، جست‌وجو و مسیر آنلاین، چهار زبان، ساخت خودکار APK.
2. **۰.۲ ✔:** ناوبری مرحله‌به‌مرحله، تشخیص خروج از مسیر، ذخیره خانه/کار/علاقه‌مندی، تاریخچه جست‌وجو، حالت شب.
3. **۰.۳ ✔ (اکنون) — آفلاین کامل:**
   - کاشی‌های PMTiles محلی + سبک و فونت محلی (نمایش نقشه بدون هیچ درخواست شبکه)
   - موتور مسیریابی آفلاین اختصاصی روی گوشی (A* روی گراف RAFG1) — بدون فورک Organic Maps و بدون نیاز به بررسی مجوز برند
   - جست‌وجوی آفلاین کامل (اندیس RAFI1، دری/پشتو/انگلیسی + نام‌های جایگزین)
   - دانلودکننده بسته داخل برنامه (manifest نسخه‌دار، ادامه دانلود، SHA-256، نصب اتمیک)
   - ناوبری با صفحه خاموش (سرویس Foreground با اعلان دائمی)
   - بسته کابل با GitHub Actions از داده Geofabrik ساخته و در Releases منتشر می‌شود
   - رعایت سیاست Nominatim (محدودسازی نرخ، کش، مدیریت 429/403) و محدودیت سرور عمومی مسیریابی
4. **۰.۴ — صدا:** حدود ۵۰ جمله ثابت دری ضبط‌شده توسط گوینده افغان (اجازه کتبی)؛ TTS فقط جایگزین.
5. **۰.۵ — پوشش کامل:** بسته‌های ولایتی به‌تدریج + بسته کشوری؛ محدودیت‌های پیچ (turn restrictions) در گراف.
6. **۰.۶ — آنلاین کامل:** سرور اختصاصی (کاشی، جست‌وجو، مسیریابی)، ترافیک جمعی ناشناس، گزارش جاده بسته، نظر و امتیاز مکان‌ها.
7. **۱.۰:** همه ولایت‌ها، F-Droid.
8. **بعد از ۱.۰:** ماژول تاکسی (پس از بررسی حقوقی).

## تصمیم زیرساخت رایگان
- **نقشه آنلاین:** OpenFreeMap (بدون کلید و بدون سرور شما). خطر: بدون تضمین دائمی بودن؛ به همین دلیل بسته آفلاین خودمان اکنون آماده است.
- **بسته‌های آفلاین:** با GitHub Actions ساخته و در GitHub Releases گذاشته می‌شوند (هر فایل زیر ۲ گیگابایت)، و برنامه از همان‌جا دانلود می‌کند.
- **جست‌وجو و مسیریابی:** با نصب بسته، کاملاً روی گوشی (موتور اختصاصی RAFG1). بدون بسته، سرویس‌های عمومی OSM با کش و محدودسازی نرخ.
