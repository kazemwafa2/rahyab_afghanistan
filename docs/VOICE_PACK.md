# بسته صدای دری (ضبط‌شده)

اندروید معمولاً صدای دری افغانستان ندارد. بهترین راه بدون سرور: یک گوینده افغان جمله‌های زیر را ضبط کند. هر جمله یک فایل کوتاه `.ogg` (Vorbis، ۲۲٫۰۵kHz مونو؛ از نسخه ۰٫۹٫۴ همه بسته‌ها OGG هستند — MP3 روی برخی دستگاه‌ها پخش نمی‌شد) است که در پوشه
`app/src/main/assets/voice/dari/`
با **همین نام‌ها** گذاشته می‌شود. برنامه خودش فایل‌ها را پخش می‌کند؛ اگر فایلی نبود از متن‌به‌گفتار گوشی استفاده می‌شود.

| نام فایل | جمله پیشنهادی |
|---|---|
| depart | حرکت کنید |
| arrive | به مقصد رسیدید |
| right | به راست بپیچید |
| left | به چپ بپیچید |
| slight_right | کمی به راست بپیچید |
| slight_left | کمی به چپ بپیچید |
| sharp_right | تند به راست بپیچید |
| sharp_left | تند به چپ بپیچید |
| uturn | دور بزنید |
| straight | به مسیر مستقیم ادامه دهید |
| roundabout | وارد دوربرگردان شوید |
| exit_roundabout | از دوربرگردان خارج شوید |
| offroute | از مسیر خارج شدید |
| rerouted | مسیر جدید محاسبه شد |
| d500 | تا پنجصد متر دیگر |
| d200 | تا دوصد متر دیگر |

نکته: ضبط در جای ساکت، یک بلندی صدا برای همه فایل‌ها، فرمت mono با حجم کم (کمتر از ۵۰ کیلوبایت هر فایل). صدای ضبط‌شده باید حق استفاده و پخش عمومی داشته باشد (گوینده اجازه کتبی بدهد).

## به‌روزرسانی v0.8.1 — ریشه مشکل بی‌صدایی و راه‌حل

**ریشه:** موتور گوگل TTS روی بیشتر گوشی‌ها هیچ صدای فارسی/دری ندارد
(فهرست زبان‌های TalkBack و Cloud TTS گوگل، فارسی را شامل نمی‌شود).
به‌علاوه دو اشکال برنامه‌ای: پخش قبل از آماده‌شدن موتور از دست می‌رفت و
شکست انتخاب زبان برای همیشه کش می‌شد.

**راه‌حل پیاده‌شده در VoiceGuide:**
- جست‌وجوی همه موتورهای نصب‌شده (`tts.engines`) و انتخاب اولین موتور دارای صدای فارسی
- صف فرمان‌های صوتی تا آماده شدن موتور + تلاش مجدد زبان
- گفت‌وگوی راهنما با دکمه «نصب صدای فارسی» (ACTION_INSTALL_TTS_DATA)
- معرفی موتور رایگان eSpeak NG (صدای فارسی آفلاین) به کاربر
- دکمه «آزمایش صدا» در تنظیمات
- زیرساخت `assets/voice/dari/` حفظ شده: هر زمان کلیپ‌های ضبط‌شده دری اضافه شوند،
  خودکار اولویت می‌گیرند (تولید خودکار صدای دری در محیط ساخت قابل اعتبارسنجی
  نبود، پس فقط صدای انسانی/موتور معتبر مجاز است — بدون صدای جعلی)

## به‌روزرسانی v0.9.3 — ۱۲ بسته صدای چندزبانه

همه صداها داخل APK هستند و کاملاً آفلاین پخش می‌شوند:

| زبان | صدا | جنسیت | موتور |
|---|---|---|---|
| دری | امیر، دلارا، فرید، نگار، همایون | ۲ مرد، ۲ زن | Piper عصبی |
| دری | عطیه، بانو | زن | عصبی (Edge Neural) |
| دری | مرد | مرد | عصبی (Edge Neural) |
| پشتو | گل‌نواز، لطیفه | ۱ مرد، ۱ زن | عصبی (Edge Neural) |
| انگلیسی | اریا، برایان | ۱ زن، ۱ مرد | عصبی (Edge Neural) |

قواعد:
- هر بسته ۲۹ پیام کامل + زنگ هشدار دارد و پیش از نمایش اعتبارسنجی می‌شود
  (بسته با کمتر از ۵ فایل هرگز فهرست نمی‌شود — ریشه اشکال «صدای خراب» v0.9.2).
- زبان راهنمای صوتی = زبان برنامه (fa/ps/en)، مستقل از زبان گوشی.
- انتخاب صدا برای هر زبان جداگانه ذخیره می‌شود: voice_pack_fa / voice_pack_ps / voice_pack_en.
- ارقام پیش از گفته‌شدن با TtsText به حروف تبدیل می‌شوند (۲۰۰ → «دوصد» در دری).
