# بسته صدای دری (ضبط‌شده)

اندروید معمولاً صدای دری افغانستان ندارد. بهترین راه بدون سرور: یک گوینده افغان جمله‌های زیر را ضبط کند. هر جمله یک فایل کوتاه `.mp3` یا `.ogg` است که در پوشه
`app/src/main/assets/voice/dari/`
با **همین نام‌ها** گذاشته می‌شود. برنامه خودش فایل‌ها را پخش می‌کند؛ اگر فایلی نبود از متن‌به‌گفتار گوشی استفاده می‌شود.

| نام فایل | جمله پیشنهادی |
|---|---|
| depart | حرکت کنید |
| arrive | به مقصد رسیدید |
| right | به راست بپیچید |
| left | به چپ بپیچید |
| slight_right | کمی به راست بپیچید |
| slight_left | کمی به چپ بپیچید |
| sharp_right | تند به راست بپیچید |
| sharp_left | تند به چپ بپیچید |
| uturn | دور بزنید |
| straight | به مسیر مستقیم ادامه دهید |
| roundabout | وارد دوربرگردان شوید |
| exit_roundabout | از دوربرگردان خارج شوید |
| offroute | از مسیر خارج شدید |
| rerouted | مسیر جدید محاسبه شد |
| d500 | تا پنجصد متر دیگر |
| d200 | تا دوصد متر دیگر |

نکته: ضبط در جای ساکت، یک بلندی صدا برای همه فایل‌ها، فرمت mono با حجم کم (کمتر از ۵۰ کیلوبایت هر فایل). صدای ضبط‌شده باید حق استفاده و پخش عمومی داشته باشد (گوینده اجازه کتبی بدهد).
