# بسته‌های نقشه آفلاین

نقشه آفلاین راه‌یاب سه بخش دارد که همه در یک فایل ZIP («بسته») می‌آیند:

1. **کاشی‌های برداری PMTiles** — برای نمایش نقشه بدون انترنت (زوم ۰ تا ۱۴)
2. **گراف مسیریابی RAFG1** — برای محاسبه مسیر موتر و پیاده روی خود گوشی
3. **اندیس جست‌وجو RAFI1** — برای جست‌وجوی خیابان، قریه، شهر و ساحه‌ها با نام دری/پشتو/انگلیسی

توضیح فنی قالب‌ها: [DATA_FORMATS.md](DATA_FORMATS.md)

## چرخه انتشار

```
Geofabrik (PBF افغانستان، ODbL)
   │  Workflow: build-map.yml (GitHub Actions — رایگان)
   ▼
استخراج منطقه (مثلاً کابل) → گراف + اندیس (tools/build_package.py)
                          → کاشی‌ها (planetiler، نسخه ثابت)
                          → بسته ZIP + pkgmanifest.json + SHA-256 (tools/validate_package.py)
   ▼
انتشار در GitHub Releases (تگ map-data) + manifest.json
   ▼
برنامه: «نقشه‌های آفلاین» → دانلود (با ادامه پس از قطع اتصال)
        → کنترل SHA-256 → نصب اتمیک → فعال شدن خودکار
```

### نکات مهم

- **Workflow ساخت بسته جدا از Workflow ساخت APK است** تا هر کدام مستقل اجرا شوند.
- نسخه داده (تاریخ PBF گئوفابریک) و checksum همیشه ثبت و منتشر می‌شود.
- فایل خراب یا ناقص هرگز منتشر نمی‌شود: اعتبارسنجی (سرآیند قالب‌ها، checksum هر فایل، اندازه کاشی‌ها) پیش از انتشار اجرا می‌شود.
- **تمام ۳۴ ولایت افغانستان** به‌صورت بسته‌های جداگانه ساخته می‌شود (کابل، هرات، قندهار، بلخ، ننگرهار، …، دایکندی). فهرست کامل و حجم‌ها در README.
- محدوده هر ولایت با حاشیه امن گرفته شده است.
- **از نسخه ۰٫۹٫۴ همه ۳۴ بسته ولایتی داخل خود APK هم هستند** (ابزار تفکیک از بسته پایه: `tools/split_base_provinces.py`) — کاربر بدون انترنت از صفحه بسته‌ها آن‌ها را نصب می‌کند.
- **مسیریابی بین‌ولایتی از نسخه ۰٫۹٫۲ با بسته پایه یکپارچه کشوری انجام می‌شود** (`graphForRouting`): اگر یک بسته ولایتی هم مبدأ و هم مقصد را بپوشاند از گراف همان ولایت، وگرنه از گراف بسته پایه — مسیر بین‌ولایتی هرگز در مرزها قطع نمی‌شود.
- **انتخاب کاشی نقشه بر اساس مکان کاربر است** (`activeMapPackage(lat, lon)`): داخل ولایتِ نصب‌شده کاشی ولایتی، بیرون آن کاشی بسته پایه؛ نقشه هیچ‌وقت خالی نمی‌شود.
- فونت گلیف داخل بسته نیست؛ از خود APK بارگذاری می‌شود (نسخه ۰.۴ به بعد).
- سهمیه GitHub Actions و دانلودها پایش می‌شود؛ هزینه صفر دائمی فرض نمی‌شود (docs/SERVER.md).

## رفتار برنامه پس از نصب بسته

- نقشه از فایل PMTiles محلی خوانده می‌شود (`pmtiles://file://…`) — **هیچ درخواست شبکه‌ای برای نقشه ارسال نمی‌شود**.
- جست‌وجو اول از اندیس محلی؛ اگر نتیجه کافی نبود و انترنت بود، Nominatim آزمایش می‌شود.
- مسیریابی و ناوبری کاملاً آفلاین روی گراف محلی انجام می‌شود (محاسبه مجدد مسیر هم).
- کش خودکار MapLibre (آنلاین) با بسته آفلاین اشتباه گرفته نمی‌شود؛ بسته یک فایل مستقل نصب‌شده است.
- حذف بسته با تأیید کاربر؛ در زمان نصب نسخه جدید، بسته فعلی دست‌نخورده می‌ماند (نصب اتمیک).

## پوشش فعلی

| منطقه | وضعیت |
|---|---|
| کابل و حومه | آماده (نمونه اولیه) |
| هرات، قندهار، مزار شریف، جلال‌آباد | تعریف‌شده در Workflow؛ با اجرای دستی ساخته می‌شود |
| همه ولایت‌ها | مرحله بعد (بسته کشوری ~۱–۲ گیگابایت) |

## آزمایش حداقلی پایان مرحله آفلاین

پس از نصب بسته کابل و فعال کردن حالت پرواز:
1. نقشه نمایش داده شود ✔
2. جست‌وجوی «کابل»، «خیرخانه»، نام خیابان‌ها کار کند ✔
3. مسیر موتر و پیاده محاسبه شود ✔
4. ناوبری و صدای دری کار کند ✔
5. خروج از مسیر و محاسبه مجدد بدون انترنت کار کند ✔
(آزمون‌های خودکار همین کارها را روی داده واقعی در `app/src/test/…/OfflineEngineTest.kt` انجام می‌دهند.)
