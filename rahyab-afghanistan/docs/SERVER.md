# سرور خودتان (برای انتشار عمومی)

سرورهای عمومی رایگان OpenStreetMap برای استفاده سنگین ساخته نشده‌اند و ممکن است برنامه شما را مسدود کنند.

**راه رایگان بدون سرور (اکنون در برنامه فعال است):** بسته‌های آفلاین (docs/MAP_PACKAGES.md) — نقشه، جست‌وجو و مسیریابی کامل روی خود گوشی کار می‌کند و فقط دانلود بسته به GitHub Releases نیاز دارد. برای اکثر کاربران همین کافی است و این سند فقط برای مرحله «آنلاین کامل» (ترافیک، گزارش جاده) است.

برای انتشار عمومی آنلاین:

- **کاشی نقشه:** OpenMapTiles/Planetiler روی داده Geofabrik افغانستان، با tileserver-gl یا PMTiles پشت یک CDN رایگان.
- **جست‌وجو:** Photon یا Nominatim (داده افغانستان؛ برای کوچک بودن منطقه سبک است).
- **مسیریابی:** Valhalla یا OSRM (پروفایل موتر و پیاده).
- یک VPS کوچک (۲–۴ گیگابایت RAM) برای افغانستان کافی است. هزینه ماهانه دارد.

بعد از بالا آوردن سرور، فقط آدرس‌ها را در `Config.kt` عوض کنید.
